# Tkinter introduction

A small desktop window for keeping a list of what is in a fridge.

## What it does

- Add an item, and the app rejects a duplicate name.
- Remove an item, and the app reports when that name is not in the list.
- Show inventory prints the current names in the window.

## Layout

- `src/introduction.py` — the window and the three actions

## Run

From the repository root:

```bash
python src/introduction.py
```

Tkinter ships with most Python installs. On Linux, the `python3-tk` package provides it.

## Stack

Python and Tkinter.
